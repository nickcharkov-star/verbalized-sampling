# Fonts

The house type, for supers and captions:

| File | Family | Licence |
|---|---|---|
| `BodoniModa-96-400.ttf`, `BodoniModa-96-400i.ttf` | Bodoni Moda, display optical size | SIL Open Font License 1.1 — `OFL-BodoniModa.txt` |
| `Jost-400.ttf`, `Jost-500.ttf` | Jost | SIL Open Font License 1.1 — `OFL-Jost.txt` |

A style pack names a font by its bare file name; autocut looks in
`$AUTOCUT_FONT_DIR` first, then here, then falls back to the system fonts.
